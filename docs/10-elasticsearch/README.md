## ⚠️ 版本与证据边界（系列统一）

| 对象 | 基线 |
| ---- | ---- |
| Elasticsearch | 8.15.3（Docker 容器，3 节点各 512m 堆，xpack.security 关闭；实验数字标注容器 vCPU） |
| Lucene | 9.x（段/倒排/merge 契约层） |
| 对比对象 | MySQL / ClickHouse / OpenSearch（机制层结论；版本级差异标注"待验证"） |

铁律：

- 三条全系列铁律：**ES 不是"能存 JSON 的 MySQL"**；**green 不等于数据绝对安全**；**会写 REST API 不等于懂 ES**
- 区分规范与实现：REST 契约/quorum 语义属规范；检测时间、队列大小、延迟数字属 8.15.3 实测
- 12 条必破神话统一编号（01~07 篇各自打破），预告与核对表见 es-00
- 全文唯一比喻"新书进馆"；所有数字要么本机实测（标注版本与环境）、要么官方文档口径、要么标注"待验证"，禁止编造
