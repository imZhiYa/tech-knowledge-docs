# 🐬 MySQL 数据库全链路系列

**数据库全链路：单机内核（一条 UPDATE 怎么跑）→ 单机并发冲突治理（为什么死锁、怎么定位、怎么治）→ 数据跨机器存活（复制与高可用）→ 可溯源兜底（备份恢复与 PITR）。**

> 主线世界观：一座图书馆。mysql-01 以「24 小时无人图书馆」讲透单机内核；后续各篇在同一宇宙内设局部比喻（便签互持、总馆-分馆传抄网络），不另起炉灶。

**因果链**：01 打穿单机内核（数据怎么存、怎么缓存、怎么定位、怎么并发正确、怎么不丢）→ 02 收口单机并发代价（锁是并发正确性的成本，死锁是成本的极端形态）→ 03 回答"一台机器不够了怎么办"（binlog 从传抄记录变成高可用地基）→ 04 兜底"机器都没了还能溯源"。

**事务专题（05）是横切入口**：把 ACID 与业务边界、并发异常、隔离级别、快照读/当前读及事务失败恢复整合为可运行的双会话实验；底层锁、MVCC、日志细节仍回链 01，死锁治理回链 02。
