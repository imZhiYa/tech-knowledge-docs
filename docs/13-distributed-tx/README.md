## ⚠️ 版本与证据边界（系列统一）

| 类型 | 基线 |
| ---- | ---- |
| Specification | 2PC / 3PC / Saga 为协议与论文级理论；X/Open XA 为接口规范；CAP 为分布式系统理论语境 |
| Implementation | MySQL 8.x InnoDB XA；Seata 1.x/2.x（AT/TCC/Saga/XA）；RocketMQ 半消息（回链 mq-07）；Go dtm |
| Version | 理论协议不分版本；各实现行为与默认参数随版本变化，实验时按实际版本核证 |
| Need Benchmark | 锁持有时长、AT undo_log 写放大、补偿延迟、悬挂扫描阈值、TC 存储模式等一律“待实测”，见 knowledge/distributed-tx/experiments EX-01~08 |

铁律：

- 不把“分布式事务”等同于任何框架：机制（协议/谱系）与实现（MySQL XA / Seata / dtm）分开陈述
- 性能数字一律标注“待实测”或“机制验证级”，禁止编造 benchmark
- 跨主题回链：Outbox/半消息回链 ddd-05、mq-07；跨片事务建模回链 sharding 主题
- 术语区分：本地事务 vs 分布式事务；协议 vs 规范 vs 实现；2PC 阻塞悬挂 ≠ TCC 业务悬挂
